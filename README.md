# The Chandu Files 🎂

A top-secret, highly classified digital birthday archive for Chandu.

## Features
* **Classified UI:** Spy-themed aesthetic with CSS variables and smooth gradients.
* **Evidence Logs:** Dedicated sections for hostel lore, joke battle warnings, and midnight laundry operations.
* **Archive Gallery:** Image grid showcasing redacted and unredacted memories.
* **Interactive Dossier:** Javascript-based page-flipping mechanism for a physical file feel.

**Threat Level:** Minoxidil Final Boss.
